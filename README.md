# 7-Day Meal Plan Prompt - Social Eagle Week 2 Day 1

A reusable prompt (not a one-off question) that produces a healthy 7-day
vegetarian South Indian weight-loss meal plan.

## Files

- `meal_plan_prompt.md` - the prompt. ROLE / FOR / CONSTRAINTS / PLAN /
  FORMAT / AVOID blocks; only the FOR block needs editing between people.
- `run1_output.md` - run with the default FOR block.
- `run2_output.md` - same prompt, FOR block changed (moderately active +
  peanut allergy). The structure held; only dishes and portions changed.

## What I changed after the first run

The first draft of the prompt did not limit cooking time and produced
weekday breakfasts with 40-minute recipes, so the FOR block gained a
cooking-time line. It also said nothing about snacks, which came back as
"fruit or nuts" every day, so the CONSTRAINTS now require named, protein- or
fibre-based South Indian snacks.

## How to reuse

Edit only the `# FOR` block (activity level, allergies, dislikes, cooking
time) and paste the whole file into any AI chat tool. The output is pinned to
one table: `Day | Meal | Dish | Portion`, 28 rows.
